# Vehicle Loan Default Prediction Using Machine Learning

**Timeline:** Nov 2025 – Jun 2026

## Problem
Lenders needed earlier, more reliable detection of high-risk loans to reduce default losses and improve credit decisioning.

## Method
- Cleaned and transformed 50,000+ loan records — handled missing values, outliers, and inconsistent formatting to improve model stability.
- Performed exploratory data analysis (EDA) to surface key risk drivers (credit history, disbursed amount, loan-to-value ratio, employment type, bureau score).
- Engineered features from raw loan and bureau data to strengthen model signal.
- Built and tuned Random Forest and XGBoost classification models via hyperparameter tuning.
- Developed a full end-to-end data pipeline from ingestion to model deployment.

## Tools & Libraries
Python, Scikit-learn, XGBoost, Pandas, NumPy, Jupyter Notebook

## Results
- Achieved **85–92% prediction accuracy** on loan default classification.
- Reduced manual analysis time by **60%** through pipeline automation.
- Improved early-risk detection to support faster, more consistent lending decisions.

## Files in this folder
- `Vehicle Loan Default Prediction.ipynb` — full notebook: data cleaning, EDA, feature engineering, modeling, and evaluation.
- `Data/` — raw input data (see note below).
- `Cleaned Data/` — processed datasets used for modeling.

> **Note on data files:** The cleaned data exports in this folder are large (10MB+ each). If you're cloning this repo for review, the notebook is the primary artifact — the full datasets are supplementary and can be regenerated by running the cleaning steps in the notebook.
