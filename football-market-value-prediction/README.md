# Market Value Prediction of Football Players Using Machine Learning

**Timeline:** Dec 2024 – Aug 2025

## Problem
Clubs and analysts needed accurate, data-driven estimates of player market value and performance to support recruitment and valuation decisions.

## Method
- Performed exploratory data analysis (EDA) across player performance, physical, and market data.
- Manipulated and queried data using SQL; processed and analyzed data with Pandas and NumPy.
- Engineered features and built machine learning models in Python to predict market value and performance.
- Ran meticulous data quality checks to improve data reliability and model performance.
- Automated data workflows with robust pipelines covering collection, cleaning, and model training.
- Built dynamic dashboards in Excel, Tableau, and Power BI to support decision-making.

## Tools & Libraries
Python, SQL, NumPy, Pandas, Matplotlib, Seaborn, Excel, Tableau, Power BI, Jupyter Notebook

## Results
- Achieved a **95% accuracy rate** in predicting player market value and performance.
- Delivered automated, repeatable data pipelines from collection through model training.
- Improved decision-making through dynamic, interactive dashboards.

## Files in this folder
- Notebook(s) covering data cleaning, EDA, feature engineering, and modeling.
- Supporting datasets used for training and evaluation.
- Dashboard files (Excel/Tableau/Power BI) used for visualizing player value predictions.
